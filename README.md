# たびメモ（試作版）

旅行にも出張にも使える、記録・経費管理アプリの試作版です。

## 使い方
1. ZIPを解凍します。
2. `index.html` をダブルクリックしてブラウザで開きます。
3. 「旅行」または「出張」を選び、タイトル・行き先・日程などを入力して保存します。
4. 記録一覧の「詳細・経費」から経費を追加できます。
5. 「旅行記録・経費一覧」または「出張報告書を印刷」を押すと、ブラウザの印刷画面が開きます。
6. メール共有ボタンはメール作成画面を開き、記録概要を本文に入れます。添付ファイルは必要に応じて手動で追加してください。

## 保存・制限
- 記録はそのブラウザの `localStorage` に保存されます。
- 別の端末への自動同期、メール認証、クラウド保存はまだ実装していません。
- ブラウザのデータ消去で記録が失われる可能性があります。定期的にJSONバックアップを保存してください。
- この試作版を公開しても、データは端末ごとに別々です。複数端末同期や利用者ごとの安全なデータ分離には、Supabase等の認証・データベース設定が必要です。
- 実際の個人情報・機密性の高い業務情報を入力する前に、十分にテストしてください。
